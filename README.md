# 2D Action Game Engine (OpenGL) | Night Knight Inspired

2D action game inspired by *Night Knight*, developed from scratch using a custom OpenGL-based engine with real-time rendering, animation systems, and enemy AI behaviors.

## Features

- Custom 2D engine built with OpenGL
- Sprite animation system (frame-based + state-driven)
- Multiple enemy types with unique AI behaviors
- Post-processing visual effects pipeline
- Audio and sound management system
- Scene and entity management architecture
- Pixel-art inspired visual style

---

## Engine Architecture

The game is built on a custom engine designed from scratch:

- Entity-component style structure
- Modular scene system
- Real-time update and render loops
- Separation between gameplay logic and rendering layer

This allows flexible expansion of gameplay systems and AI behaviors.

---

## Rendering System

Built using OpenGL with GLSL shaders:

- 2D sprite batching system
- Texture atlas support
- Camera system for world movement
- Post-processing effects (screen shaders)
- Efficient real-time rendering pipeline

---

## Animation System

The sprite animation system supports:

- Frame-based animations
- State-driven transitions (idle, attack, move, etc.)
- Event-triggered animation changes
- Smooth blending between animation states

---

## Enemy AI

Multiple enemy types with distinct behaviors:

- Patrol-based enemies
- Aggressive chase AI
- Range-based attack patterns
- Simple state machines for behavior control

Each enemy type is designed to create different gameplay challenges.

---

## Audio System

Custom audio manager includes:

- Sound effect playback
- Background music support
- Event-based audio triggers
- Lightweight integration with gameplay systems
